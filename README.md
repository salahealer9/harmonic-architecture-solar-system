# The Harmonic Architecture of the Solar System

**A Silver-Ratio-Based Hypothesis for Planetary Spacing**  
**Salah-Eddin Gherbi** · Independent Researcher, United Kingdom

## Latest manuscript — Version 3.1 (11 October 2026)

**Revised preprint, published on Zenodo:** [10.5281/zenodo.23301593](https://doi.org/10.5281/zenodo.23301593)

[Read the v3.1 PDF in this repository](v3.1/manuscript/SRHF_v3.1_ZENODO_FINAL.pdf) · [Zenodo record](https://zenodo.org/records/23301593)

Version 3.1 corrects the numerical reporting, comparator definitions, data-provenance statements and interpretative limitations of the historical versions, **without changing the Silver-Ratio Harmonic Framework (SRHF) mathematical prescription**.

The fixed prescription describes nine observed Solar System bodies (eight planets and Pluto, a dwarf planet) with **MAPE 0.792970%** and **RMSE 0.105821 AU**, using the explicitly declared rounded semi-major axes and Earth = 1 AU normalization. The hypothetical *Harmonia* node at approximately **2.142136 AU** is **not observed** and is excluded from the observational error scores.

For the *same six classical planets* under the stated C6 evaluation protocol, the respective MAPE values are **0.8954%** for fixed SRHF, **2.6806%** for the specified Titius–Bode model and **17.5152%** for the idealised Kepler-solids construction. These are descriptive comparisons under particular prescriptions, not evidence that SRHF is uniquely or physically preferred.

The empirically fitted outer-five optimum, **2.143687394 AU**, is distinct from the fixed Silver node. The Harmonic Spread Index (HSI) measures the dispersion of percentage residuals; it is **not** a measure of gravitational stability. The model is a **phenomenological spacing hypothesis**, not an established planetary formation mechanism, a detection of a lost planet, proof of physical quantisation, or a demonstrated statistical-significance result.

The orbital inputs are author-adopted rounded values compiled from earlier published reference materials; the precise source editions, orbital-element conventions and reference epochs have not been fully reconstructed. See the manuscript for the full methods, tests, and limitations.
